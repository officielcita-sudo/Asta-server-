What we check

The basics attackers look for first

Most breaches start with something simple left misconfigured. Each scan looks at the same signals an attacker would see, without touching anything.

Encryption & certificates

Is HTTPS on, is the certificate trusted and current, and does plain HTTP redirect to the secure site?

Security headers

HSTS, Content-Security-Policy, clickjacking protection and MIME-sniffing defenses, checked and explained.

Cookie hygiene

Session cookies missing Secure or HttpOnly flags are an easy target. We flag every one.

Information leaks

Server banners that advertise exact software versions make it easy to match you to known exploits.

Modern TLS only

Outdated protocol versions are flagged so you can retire them before they become a compliance issue.

FAQ

Questions, answered

Is the scan safe to run on my live site?

Yes. The free scan is passive: it makes a couple of ordinary page requests and opens a TLS connection, the same thing a visitor's browser does. It never tries to log in, submit forms or exploit anything.

Can I scan any website?

Please only scan websites you own or have permission to assess. Scans are rate-limited and private network addresses are blocked.

Is it really free?

Yes. Every tool on this site is free, with no account, trial or credit card. There is no paid version.

Is this a full penetration test?

No. The automated scan covers common configuration issues that attackers look for first. For an in-depth assessment of a complex application, hire a professional penetration tester.

How does the email check protect my privacy?

You can only see the report for an email you can receive mail at: we send a one-time code first. Results are shown once and never stored, and password checks happen inside your browser.

Do you store my results?

No. Website scans and email reports are shown to you and then discarded.
